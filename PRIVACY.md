# Mathbox privacy policy

Effective date: October 2, 2026

Mathbox is an open-source collection of mathematical research skills and
optional helper scripts maintained by Najib Idrissi-Kaïtouni. This policy
covers Mathbox itself and support through its GitHub repository.

## Plugin use

The maintainer does not automatically collect personal data through Mathbox.
The plugin has no maintainer-operated backend, user accounts, analytics,
tracking, or telemetry, and does not send your conversations, manuscripts,
research files, or generated results to the maintainer. The maintainer does
not sell personal data or use it for advertising.

The AI application you use to run Mathbox processes the prompts and files
you make available to it. Mathbox workflows may read and write research
artifacts in your working environment and use the application's tools to
consult external sources or carry out tasks you authorize. Your AI provider
and any external services you use handle data under their own policies and
settings; this policy does not govern those services.

## Storage and control

Optional helper scripts can store research records, source caches, logs, and
results in your working environment. These files remain there until you
remove them; Mathbox provides no automatic expiration. You control which
files and tools the host application can access, whether to run the helpers,
and when to delete their outputs. You can disable or uninstall the plugin
through your host application. Uninstalling does not delete existing research
files. The maintainer retains no copy of data from ordinary plugin use.

## GitHub support

If you open an issue, the maintainer receives your GitHub username and any
profile information, messages, or attachments you choose to share. This
information is used to respond to requests and maintain Mathbox. Issues are
public: GitHub hosts them and anyone can read them. Support records are
retained indefinitely as project history unless edited or removed. You can
edit your contributions or request removal of content the maintainer controls;
GitHub's own retention and privacy practices still apply.

For support or privacy questions, use
[GitHub issues](https://github.com/nidrissi/mathbox/issues). Do not include
confidential research, credentials, or sensitive personal information in a
public issue.
