# Bounded novelty check

> Every operator in class K sends bounded sequences to sequences with convergent
> subsequences.

survey in the supplied source bundle instead uses the historical phrases
“completely continuous operator” and “precompact image,” and cites an older
primary paper. Only the survey abstract has been read; the cited theorem and its
hypotheses have not.

Design and carry out the bounded source check supported by the available
material. State an overlap classification only to the verified scope.
